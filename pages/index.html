CORE PROTOCOL // 核心技術

三大實驗室數據核心

將不可見的感官體驗轉化為公開的精確數據指標，消除風味的不確定性，確保都會日常的純粹清醒體驗。

PROTOCOL // 01

單一莊園溯源

公開每支豆子的海拔高度、微型氣候、土壤成分與處理法數據。完整記錄生豆含水率與密度，從源頭鎖定純淨基底。

PROTOCOL // 02

曲線精準烘焙

電腦全時監控溫升率（RoR），以精密曲線鎖定最純淨的果酸與甜感，隔絕雜味產生，精準呈現產區風土特質。

PROTOCOL // 03
